# Adaptive PPO-Based Resource Orchestration for Cloud-Edge AI Inference

This repository contains the reproducibility package for the study **Design and Evaluation of Adaptive PPO-Based Resource Orchestration for Latency-Sensitive AI Inference in Cloud-Edge Computing**.

## Scope

The study uses an **event-based analytical simulation**. It does not execute ImageNet/CIFAR-10 samples and does not claim hardware-measured power or measured classification accuracy. The reported model-quality quantity is an **analytical accuracy-retention score**. The simulator evaluates local, edge, cloud, partitioned, and reduced-precision execution actions under normal, burst, deterministic network-fluctuation, and energy-constrained scenarios.

## Repository contents

- `code/revised_framework.py` - complete executable implementation.
- `code/CloudEdge_PPO_Revised.ipynb` - Jupyter notebook version.
- `code/cells/` - the same workflow split into nine sequential Python files.
- `config/experiment_config.json` - parameters, training seeds, validation offsets, and evaluation seeds.
- `results/results_raw.csv` - raw per-seed evaluation results.
- `results/results_summary.csv` - mean and standard-deviation summary.
- `results/paired_statistics.csv` - paired Wilcoxon tests with Holm adjustment.
- `results/ablation_raw.csv` and `results/ablation_summary.csv` - ablation outputs.
- `results/training_history.csv` - PPO training history for four scenarios.
- `checkpoints/` - trained PPO checkpoints for the four scenarios.
- `figures/` - four experimental figures generated by the implementation.
- `verify_repository.py` - consistency check for configuration, CSV outputs, statistics, ablation results, and checkpoint reproducibility.

## Installation

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
```

## Reproduce the complete experiment

```bash
python code/revised_framework.py
```

The full run trains four PPO policies, evaluates five baselines plus PPO on ten matched seeds, performs the ablation study, and writes CSV/JSON/PNG outputs. Runtime depends on the processor.

## Verify the archived results

```bash
python verify_repository.py
```

The verifier regenerates the summary statistics and Wilcoxon/Holm results from the raw CSV files and reloads the four saved checkpoints to reproduce the archived raw results.

## Main experimental protocol

- Devices: 2
- Edge servers: 2
- Cloud nodes: 1
- Training episodes: 100 per scenario
- Tasks per episode: 120
- Evaluation seeds: 1000-1009
- Ablation training: 30 episodes per variant
- Scenarios: normal, burst, fluctuation, energy constrained
- Policies: Local-only, Edge-only, Cloud-only, Static, Heuristic, PPO
