# v2.0 – Reviewer-revision release

This release replaces the original scenario-specific 120-task experiment. It is not backward-compatible with the originally submitted numerical tables. All manuscript result tables must use the CSV files in this release.

Key corrections: dynamic scenarios span complete cycles; capacities are balanced; radio energy excludes propagation; unsupported precision compute-speed scaling is removed; PPO is unified across scenarios; DQN and exhaustive constant-action comparators are added; final evaluation uses 20 seeds; policy entropy/state dependence and sensitivity are reported; all paired tests use one global Holm family; effect sizes and confidence intervals are included; figures are regenerated as SVG/PNG.
