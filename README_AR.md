# حزمة إعادة الإنتاج بعد تعديلات المحكمين – الإصدار v2.0

أُعيد بناء التجربة لمعالجة الملاحظات الجوهرية للمحكمين: سياسة PPO موحدة لكل السيناريوهات، أفق زمني 45 ثانية يغطي دورة التذبذب كاملة وفترتي الاندفاع/التعافي، إعادة موازنة قدرات طبقات device/edge/cloud، تصحيح طاقة الإرسال لتُحسب خلال زمن التسلسل فقط، جعل قيد البطارية فعّالًا، وإضافة تذبذب شبكة مضبوط بالبذور.

أضيفت مقارنات DQN، وأفضل فعل ثابت يتم اختياره على بذور تحقق منفصلة، وسياسة greedy أحادية الخطوة، كما أضيف فحص اعتماد السياسة على الحالة، إنتروبي التدريب، اختبار PPO الحتمي والعشوائي، تحليل حساسية، أحجام أثر وفترات ثقة، وتصحيح Holm عالمي لكل الاختبارات.

الدراسة الأساسية ما تزال محاكاة تحليلية. ملف `code/hardware_microbenchmark.py` يضيف قياس زمن تنفيذ حقيقي على CPU لـ ResNet-50 وMobileNetV2 كاختبار sanity check فقط، من دون ادعاء قياس طاقة أو دقة تصنيف أو تمثيل عتاد edge/cloud حقيقي.

لإعادة تشغيل التجربة كاملة:

```bash
python code/revised_framework.py
```

وللتحقق السريع من اتساق الملفات الناتجة:

```bash
python verify_repository.py
```

الحزمة جاهزة للإيداع كإصدار GitHub/Zenodo. إنشاء DOI الأرشيفي يحتاج إلى حساب مالك المستودع، لذلك لم يتم اختلاق DOI داخل المخطوط.
